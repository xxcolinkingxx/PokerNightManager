# Poker Night Manager

## Vision

Poker Night Manager is a premium mobile-first Progressive Web App designed to completely manage home poker games.

The application should feel like a native iPhone application.

Every interaction should feel polished, modern, and premium.

The goal is to become the best home poker management software available.

---

# Design Philosophy

The application should resemble:

- Apple Wallet
- Apple Fitness
- Apple Stocks
- Premium casino software

Never resemble Bootstrap.

Never resemble Material Design.

Everything should feel custom.
